# ECHELON — Master product and implementation directive
## Governing principle
Build **ECHELON**, the new independent WHINK Group personal AI organizational operating system, using the Founder-approved WHINK Ultimate vision and the existing KAMSI-PRIME/HOLO code. This is a quality-preserving reconstruction and consolidation, **not** a clean-sheet rewrite. Operate only in ECHELON. Protect the original KAMSI-PRIME remote as a read-only source and preserve its Git history.

Read `ECHELON-START-HERE.md` and all architecture-control files before writing code. Approved decisions FDR-001..029 govern; later explicit Founder changes override only what they address. The historical KAMSI file names and PR numbers are provenance, not target-repo execution instructions.

Progress claims must say what is *actually* implemented, tested and unverified.
