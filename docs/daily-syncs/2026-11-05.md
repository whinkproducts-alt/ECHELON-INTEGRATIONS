## C02 — account-scoped dispatch admission and accounting

Implemented on the existing `usage_events` table (no second source of truth):

- `lib/model-router/admission.ts`: one pure policy (`MISSING_ACCOUNT`, `LOCKDOWN`, `LOCAL_ONLY`,
  `TRIAL_NOT_ADMITTED`, `UNKNOWN_COST`, `PAID_NOT_ADMITTED`, `UNKNOWN_PRICE`, `SPEND_CAP_UNSET`,
  `SPEND_HARD_LIMIT`, `TOKEN_HARD_LIMIT`), plus `reserveDispatch` / `settleDispatch` / `holdDispatch` /
  `releaseDispatch` / `reconcileDispatch`. Reservation locks the user row (`SELECT … FOR UPDATE`),
  sums current-month settled usage and **all open holds regardless of month**, and commits before any
  network call. Settlement is single-use and account-scoped. A lost/timeout/cancel response becomes a
  `held` row that survives UTC rollover; only a proven pre-transport failure is released.
  Reconciliation is a read and never retries the external call.
- Paid dispatch stays blocked: it needs `WHINK_PAID_MODELS_ENABLED=true`, a known price and a positive
  `WHINK_MONTHLY_SPEND_MICROS`. A BYOK key, an unset cap or a zero cap never authorises spend.
- `lib/model-router/dispatch.ts`: `admittedCall` / `admittedChatOnce` / `admittedEmbed` /
  `reserveVoice` / `runAdmittedVoice`.
- Wired the real production paths: tool loop (each tool round + tools-unsupported stream fallback),
  worker `workerAsk`, auto-memory extraction, orchestrator debrief, tool postmortem, skills security
  review and committee votes, swarm planner and agent calls, change-request refinement, embeddings
  (remote embedding without an account now returns `null` instead of calling out), and both voice
  routes.
- Schema: additive migration `20261105070000_dispatch_admission` adds attempt key, purpose, state,
  cost class/price snapshot, micro-USD hold, uncertainty, period and settlement time, plus a unique
  `(userId, attemptKey)` and `(userId, state, periodStart)` index. Legacy rows stay `state=recorded`
  with a null key. `budgetState` now also counts open holds opened in earlier months.
- Chat route returns a visible `409` with the refusal code instead of a generic 502.
